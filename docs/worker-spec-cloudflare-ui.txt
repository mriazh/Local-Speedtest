Redesign the Local Speedtest web frontend (web/index.html, web/style.css, web/app.js) into an authentic Cloudflare Speed Test (speed.cloudflare.com) inspired dark theme.

Reference & Design Standards (Cloudflare Speed Style):
1. Visual Aesthetic:
   - Palette: Deep black background (#0a0a0c), sleek card surfaces (#121316 to #18191e), sharp borders (#22242c), clean tabular typography.
   - Accents: Cloudflare Iconic Orange (#f6821f) for Download/primary CTAs, Vivid Purple (#8a63d2) for Upload, Electric Cyan (#00a4e4) for Latency, Amber (#f59e0b) for Jitter.
   - Top Navigation/Header:
     * Brand: Clean cloud/speed icon + "Local Speedtest" (speedtest.mriazh.my.id).
     * Server Pill: "Debian PC • 172.16.171.23 • 100% Local LAN (Zero Internet Quota)".
     * Client IP badge (from getIP).
   - Stepper Header:
     * 4-Phase Step Indicator: [1. Latency] -> [2. Download] -> [3. Upload] -> [4. Complete] with active orange glow.
   - Hero Live Area:
     * When idle: Large prominent "START SPEED TEST" button with glowing hover state.
     * When running: Huge live digital readout (e.g. 345.2 Mbps) with real-time live sparkline canvas/SVG graph displaying throughput over time.
   - The Iconic Cloudflare 4-Card Metric Matrix:
     * Card 1: DOWNLOAD (Mbps) + mini sparkline chart + peak/avg.
     * Card 2: UPLOAD (Mbps) + mini sparkline chart + peak/avg.
     * Card 3: LATENCY (Ping ms) + min/avg latency.
     * Card 4: JITTER (ms) + connection rating badge ("Ultra Stable").
   - Shareable Result Section (appears on test completion):
     * Shareable link input with 1-click "Copy Link" button (http://speedtest.mriazh.my.id:8989/results/?id=<id>).
     * "Open Result Card" button linking to /results/?id=<id>.
     * "Test Again" button.

2. Technical Integration:
   - Must use web/speedtest.js and web/speedtest_worker.js.
   - Speedtest parameters:
     s.setParameter("telemetry_level", "basic");
     s.setParameter("url_telemetry", "results/telemetry");
     s.setParameter("url_dl", "garbage");
     s.setParameter("url_ul", "empty");
     s.setParameter("url_ping", "empty");
     s.setParameter("url_getIp", "getIP");
     s.setParameter("test_order", "IPDU");
   - Telemetry: capture testId on completion, generate share URL, copy to clipboard.
   - Preserve web/results.html viewing page compatibility.
   - Ensure config/settings.toml has assets_path = "web".
   - 100% offline LAN compatible (no external Google Fonts or CDNs).
