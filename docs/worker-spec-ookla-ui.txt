Redesign the Local Speedtest web frontend (web/index.html, web/style.css, web/app.js) into an authentic Speedtest.net (Ookla) / OpenSpeedTest inspired dark UI.

Design Reference & Standards:
1. Visual Layout (Ookla / Speedtest.net Dark Aesthetic):
   - Centerpiece: ONE large circular speedometer gauge (320px - 380px diameter).
   - In the center of the gauge: a prominent, glowing circular "GO" button with smooth hover animation.
   - When test starts, the "GO" button fades into a live digital speed readout (e.g. "345.2 Mbps") with an active glowing needle / progress arc sweeping across a semi-circular or 240-degree tachometer dial with tick marks: 0, 10, 50, 100, 250, 500, 1000, 2000 Mbps.
   - Clean telemetry bar at the top or flanking the gauge:
     * PING (ms) with amber indicator
     * JITTER (ms) with amber indicator
     * DOWNLOAD (Mbps) with cyan (#00f2fe) indicator
     * UPLOAD (Mbps) with purple/violet (#818cf8) indicator
   - Local IP / Provider badge at the bottom (e.g., "172.16.171.24 • Local LAN").
   - Result card appearing cleanly below or in-place upon test completion:
     * Download, Upload, Ping, Jitter summary
     * Shareable Link input with 1-click "Copy" button
     * Link to view full generated card: /results/?id=<id>

2. Technical Integration:
   - Must use web/speedtest.js and web/speedtest_worker.js (official multi-stream Web Workers).
   - Parameters:
     s.setParameter("telemetry_level", "basic");
     s.setParameter("url_telemetry", "results/telemetry");
     s.setParameter("url_dl", "garbage");
     s.setParameter("url_ul", "empty");
     s.setParameter("url_ping", "empty");
     s.setParameter("url_getIp", "getIP");
     s.setParameter("test_order", "IPDU");
   - Update config/settings.toml to ensure assets_path = "web".
   - 100% offline LAN compatible (no external fonts, scripts, or CDNs).
   - Responsive for mobile (iPhone/Android) and desktop.
   - Keep results.html working for /results.html?id= viewing.
