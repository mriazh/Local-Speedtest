Redesign the Local Speedtest web frontend (web/index.html, web/style.css) into a high-end, modern dark-mode UI with animated speedometer gauges, powered by the official multi-threaded LibreSpeed engine (web/speedtest.js and web/speedtest_worker.js).

Read existing files first:
- web/speedtest.js (already placed in web/)
- web/speedtest_worker.js (already placed in web/)
- config/settings.toml
- docs/design.md

Design & Requirements:
1. Technology:
   - Frontend must use `speedtest.js` and `speedtest_worker.js` for multi-threaded sustained testing (10-15s multi-stream) to fully saturate 1 Gbps / 2.5 Gbps LAN.
   - Configure speedtest parameters:
     s.setParameter("telemetry_level", "basic");
     s.setParameter("url_telemetry", "results/telemetry");
     s.setParameter("url_dl", "garbage");
     s.setParameter("url_ul", "empty");
     s.setParameter("url_ping", "empty");
     s.setParameter("url_getIp", "getIP");
   - Update config/settings.toml so `assets_path = "web"`.

2. Aesthetic & Visual Quality (Antislop / High-end UI):
   - Premium dark theme: deep slate/obsidian (#0b0f19 or #090d16), surface cards (#131b2e), subtle glowing borders (#1e293b to #334155).
   - Speedometer gauge: canvas-based or SVG arc meter that smoothly animates in real-time as speed increases.
   - Distinct metric accents:
     * Ping & Jitter: Crisp amber/gold (#f59e0b)
     * Download: Electric cyan/blue (#00f2fe / #38bdf8)
     * Upload: Neon emerald/purple (#10b981 / #818cf8)
   - Large prominent "START TEST" button with glowing hover and active animation.
   - Stage progress indicator showing current phase: "Pinging...", "Testing Download (Multi-stream)...", "Testing Upload (Multi-stream)...", "Completed".
   - Clean result box appearing on test completion with:
     * Big summary numbers
     * Shareable link input + "Copy Link" button
     * "View Generated Card" link pointing to `/results/?id=<id>`
     * Responsive: perfect on mobile (iOS Safari / Android Chrome) and desktop.
   - 100% offline LAN compatible (no CDNs, all CSS and JS local).

3. Validation:
   - Check HTML syntax and JS error-free.
   - Ensure settings.toml is set to `assets_path = "web"`.
